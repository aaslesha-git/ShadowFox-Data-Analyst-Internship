# Task 3 – Customer Churn & Retention Dashboard

## Overview

This project was completed as part of the Advanced Level Data Analyst Internship task at ShadowFox.

The project analyzes customer churn and retention patterns using the Telco Customer Churn dataset. An interactive dashboard was created using Microsoft Power BI to help understand customer behavior and identify segments associated with higher churn.

## Objectives

* Clean and prepare the customer churn dataset.
* Calculate key customer and churn KPIs.
* Analyze churn across different customer segments.
* Create an interactive Power BI dashboard.
* Identify important customer churn patterns.
* Provide business-focused insights and recommendations.

## Dataset

The project uses the Telco Customer Churn dataset containing customer information such as:

* Customer ID
* Gender
* Senior Citizen
* Partner
* Dependents
* Tenure
* Internet Service
* Contract
* Payment Method
* Monthly Charges
* Total Charges
* Churn

## Tool Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization

## Data Cleaning

The dataset was prepared using Power Query.

The cleaning process included:

* Checking the dataset structure.
* Removing unnecessary columns.
* Checking for blank and error values.
* Converting numerical fields to appropriate data types.
* Preparing the data for analysis and visualization.

## KPIs

The dashboard includes the following key performance indicators:

* Total Customers
* Churned Customers
* Churn Rate
* Average Monthly Charges

## Dashboard Visualizations

The dashboard contains:

1. Customer Churn by Contract
2. Customer Churn by Internet Service
3. Customer Churn by Tenure
4. Churned Customers by Payment Method
5. Average Monthly Charges by Churn

## Interactive Features

The dashboard includes slicers for:

* Contract
* Gender
* Internet Service

These filters allow users to explore customer churn patterns across different customer segments.

## Key Insights

* Month-to-month customers show higher churn compared with longer-term contract customers.
* Customer churn varies across different internet service types.
* Customers with shorter tenure represent an important segment for churn analysis.
* Payment method patterns show differences in customer churn behavior.
* Average monthly charges differ between customers who churn and customers who remain.

## Business Recommendations

* Encourage customers to move from month-to-month contracts to longer-term plans.
* Focus retention efforts on customers during their early tenure.
* Investigate service-related factors among customer groups with higher churn.
* Review payment-method patterns to identify possible customer experience improvements.
* Use the dashboard to regularly identify customer segments requiring retention attention.

## Conclusion

This project demonstrates the process of transforming a realistic customer dataset into an interactive business dashboard. The analysis combines data preparation, KPI development, visualization, interactive filtering, and business recommendations to support customer retention analysis.
